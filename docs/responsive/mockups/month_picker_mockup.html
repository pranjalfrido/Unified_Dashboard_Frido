What changes

  • One pill instead of two controls. It shows the selection in words ("Apr – Jul 2026") and a count chip ("4 mo"). The separate "4 of 9" dropdown and the search box go away.
  • Quick presets on the left: Latest month, Last 3, Last 6, FY 2026–27 to date, All available. Each shows its range, so you know what you'll get.
  • Month grid by year (Jan–Dec, ‹ › for years). Months without billing data are greyed and can't be picked, so there's no empty selection.
  • Range (default): click the start month, then the end month; the band between them fills. Pick months: click any months on/off, the same as today's checkboxes, for gaps like "Apr + Jun".
  • Apply runs the query once (no reload on every click). Esc or clicking outside cancels. The footer always shows what will be applied.
  • Mobile: a bottom sheet with preset chips, the month grid (always visible, bigger tap targets) and a sticky "Apply · Apr – Jul 26". Range only on mobile (no Pick months toggle); if custom months were picked on laptop, the pill shows "5 months" and the first tap starts a new range.
  • Numbers unchanged: the picker outputs the same list of billing months the current dropdown sends. Only the control changes.
