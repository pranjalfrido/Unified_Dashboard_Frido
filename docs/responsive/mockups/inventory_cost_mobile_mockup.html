What changes vs the current build

  • Header: shorter title "Inventory cost", 36 px 🔍 + Product/SKU toggle (same as Inward's SKU/Sub-cat toggle). The ⋯ menu moves into the full-screen list (Export CSV, No-COGS list). Subtitle shows "Top 10 of N products/SKUs · by value".
  • COGS line: shows the month the rates actually come from ("Sep 2026, carried forward"), not the calendar month.
  • Tiles: no selected border by default. Third tile renamed "No COGS", amber, value + "SKUs · units", tap opens screen 4.
  • Product view (default): variants grouped by product (sub-category). Value, units and avg sale are sums; COGS/unit = value ÷ units; DOI = units ÷ avg sale. Status chip follows the product's DOI.
  • Product sheet: totals + all variants (sorted by value), each tappable → existing SKU detail sheet. Status shown as a coloured chip, not grey text.
  • SKU view: today's list, with the product name as the second line.
  • No COGS: in-stock SKUs only; split into "valued at sub-cat avg" vs "not valued", with units and a fix hint. Counts must match the laptop card.
